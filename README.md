# masuidrive-kbd

スマホ幅とタブレット幅で使える、オフライン日本語入力対応の Android IME です。Foldでは閉じたスマホ幅と開いたタブレット幅の両方へ同じ操作体系で対応します。かな、テンキー、絵文字、QWERTY、記号、音声の4行レイヤーを Custom View で描画し、絵文字のrecentは端末内だけに保存します。同梱した Mozc 辞書でかな漢字変換と確定後の次単語予測を行います。入力文字をログや端末外へ送信しません。

現行の公開準備版は **v0.15.19**（versionCode 35）です。配布用の未圧縮APK名は `gesture-ime-v0.15.19.apk` です。

## 必要な環境

- JDK 17
- Android SDK 36
- Android Emulator または Android 9（API 28）以降の arm64-v8a 端末

## ビルドとテスト

```sh
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew testDebugUnitTest lintDebug assembleDebug
```

全ローカル検証は `scripts/test-all.sh` で実行します。接続済みエミュレータで実Mozcテストも行う場合は `scripts/test-all.sh --connected` を使います。接続テストは端末へAPKを導入するため、通常の検証から明示的に分けています。

APKは `app/build/outputs/apk/debug/app-debug.apk` に生成されます。

## エミュレータで試す

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell ime enable com.masuidrive.gestureime/.ImeService
adb shell ime set com.masuidrive.gestureime/.ImeService
```

アプリ一覧から **masuidrive-kbd** を開き、「入力を試す」を選びます。物理キーボードが接続されたエミュレータでソフトウェアキーボードが出ない場合は、エミュレータ側で画面キーボード表示を有効にしてください。

セットアップ画面は、status barの下に固定した「masuidrive-kbd 設定」バーから戻れます。設定内容だけをスクロールでき、Light/Darkのsystem bar iconもAndroidテーマへ追従します。

入力設定の「キーボードの高さ」では小・標準・大を選べ、初期値は標準です。小は50dp row pitchで208dp、標準は55dpで228dp、大はスマホ幅で60dp・248dpです。大を選んだ600dp以上の画面では、Dual Flick導入前から使っていた62dp row pitch・256dpを維持します。選択済みの高さはIME再表示やアプリ切替後も維持します。候補欄50dpとnavigation barのsafe areaはキー4行の高さへ加えません。

左下のレイヤーキーは、左へフリックすると音声入力、上で日本語、右でQWERTY、下でテンキーへ切り替えます。記号は「?}」キーで開きます。Enterは上フリックでCtrl+J、下でPasteです。候補内容が変わると候補欄は先頭へ戻り、選択中候補だけをaccent色で示します。独自のキーボードを閉じる行はなく、AndroidのOS操作でIMEを閉じます。

入力欄を開いたとき、数字・電話番号・日時はテンキー、URL・メールアドレス・パスワード・ASCII強制欄はQWERTYを表示します。通常の文章欄と未指定の入力欄は、最後に手動で選んだレイヤーを開きます。入力種別による自動選択では、この保存済みレイヤーは変更しません。「入力を試す」画面の通常・数字・メールアドレス・パスワード欄で切替を確認できます。

テンキーの`.`はタップで`.`、左フリックで`,`、右フリックで`=`を入力します。上・下フリックには文字を割り当てていません。

日本語変換中はSpaceが「候補」になり、タップで候補を選択・巡回します。候補を選ぶ前のEnterは「無変換」で元のひらがなを確定し、候補を選ぶと「確定」に変わって選択中候補を確定します。Enterの左または上フリックは、どちらの状態でも全角カタカナを確定します。

日本語・テンキー左上の☺で絵文字レイヤーを開きます。候補欄の位置にAndroidX Emoji Pickerのカテゴリicon行が表示され、開くたびにRecentと一覧先頭へ戻ります。カテゴリiconはすべて固定48dp幅です。左端はかなレイヤーと同じ幅で、上からあ、?}、19、AZの切替列です。右側は最下段まで4行7列の縦スクロール一覧で、wide画面でも各セルを7分割slotの中央へ揃えます。絵文字レイヤーに削除キーはありません。Recentは端末内で新しい順・重複なしに最大100件保存し、101件目では最も古い1件を除きます。private入力欄ではRecentを表示・保存しません。記号2行目の]右0.5wは⌫で、tap削除・下フリックEscです。

音声入力レイヤーは候補が空、権限未許可、端末非対応の状態でも最下段のキャンセル・状態・句読点・Space・削除・Enterを露出し、キャンセルで直前の文字レイヤーへ戻れます。Spaceフリックは通常欄では選択位置を直接変更し、抽出テキストを返さない、または選択変更を拒否する非private入力先だけDPAD矢印へ自動fallbackします。成功応答だけ返して移動を無視するターミナルには、設定の「ターミナル向けカーソル操作」で非private入力先へのDPAD送信を強制できます。private入力欄では自動fallbackでも手動設定でもDPADを送りません。

見えるキー間の横6dp・縦10dpの隙間も、中央を境に最寄りのキーへ割り当てます。キーの形状と間隔を保ったまま隙間付近のタップを受け付け、EMPTYで予約した領域は入力しません。フリック方向の判定閾値は18dpのままです。

候補faceは最上段key faceから10dp離し、先頭候補の左外周もphone幅では6dp、wide幅では13dpで最左key faceへ揃えます。候補の高さ38dp、候補間5dp、横スクロール、長押し操作は変わりません。

## プライバシー

Manifestに `INTERNET` 権限はありません。通常欄では、確定した日本語変換をMozcの履歴へ端末内保存して候補順位を学習します。確定後の次単語予測もカーソル周辺の最大128 code pointを端末内Mozcへだけ渡します。Mozc候補を長押しすると、その候補の履歴学習を削除できます。パスワード欄と `IME_FLAG_NO_PERSONALIZED_LEARNING` 指定欄では、Mozc候補、次単語予測、学習、貼り付け、音声入力を無効にし、周辺文字列を取得しません。

Android個人辞書は初期状態で有効です。設定画面の「Android 個人辞書を使う」で無効にできます。登録語のショートカットが入力中の読みに一致する語を候補へ表示し、データを複製・送信しません。

英数字候補は初期状態で有効です。設定画面で無効にできます。入力したASCII英数字は自動置換せず、固定された端末内辞書の候補をタップした時だけ置換確定します。Spaceは原文確定後に空白を入力し、Enterは原文だけを確定します。private入力欄では英数字候補も無効です。

Android 12以降では、左下のレイヤーキーを左へフリックすると、端末内日本語モデルが利用できる端末に限り音声入力レイヤーで認識を開始します。最下段は6等分で、キャンセル、非操作の「認識中」、句読点、Space、削除、Enterの順です。「認識中」の横にはマイク入力に追従する小さな波形が出て、候補選択待ちや取消では消えます。句読点はtapで「、」、左で「。」、上で「？」、右で「！」、下で「、」を直接確定し、Mozcの読みには加えません。表示中の「、。？！」は全てフリックでも入力できます。削除はtapだけで直前の1文字を消し、SpaceとEnterは他レイヤーと同じフリックを使います。これらの編集操作中も認識・音声候補を維持します。最終候補は通常の横候補欄ではなく固定された音声パネルに1行ずつ縦に表示し、似た候補では異なる文字だけを青い太字で示します。最終結果がないときは、最後の有効な途中結果を選択可能な候補として表示します。候補を確定すると同じ入力欄へ1回だけ入力し、一覧を消して音声入力レイヤーのまま直ちに次の認識を開始します。無言のまま端末内認識が時間切れになってもエラー表示へ移らず、自動的に認識を再開して次の発話を待ちます。キャンセルまたはレイヤー・入力欄の切替まで繰り返せます。マイク権限はSetup画面からユーザー操作で許可します。端末内モデルがない場合と無音以外の認識エラーはタップできないテキストで表示し、ネットワーク認識への切替や自動再試行はしません。

QWERTYの2行目右端は0.5wの`.`で、タップで`.`、下フリックで`?`を入力します。3行目右端は1wのBackspaceで、タップで削除、下フリックでEscを送り、左・上・右は入力しません。記号レイヤーの配置は変わりません。

QWERTYで「/」を入力すると、設定した最大6個のスラッシュコマンド候補を表示します。初期値は`/compact`、`/clear`、`/quit`です。候補をタップした場合だけ、入力中の「/」を置き換えて確定します。

# v0.15.31 メモリ観察（2026-10-13）

公開済み `gesture-ime-v0.15.31.apk` を Android 16 / API 36.1 の `Medium_Phone_API_36.1` AVD に導入し、設定アプリの検索欄で実際の IME を表示した。プロセス PID `32736` を通して `adb shell dumpsys meminfo com.masuidrive.gestureime` の PSS/RSS と View 数を採取した。端末密度は 420 dpi。通常幅 1080px（約 412dp）と、一時変更した 2205px（840dp）の両方を確認した。

| 操作 | 最初の PSS | 最後の PSS | 5秒後の PSS | View 数 |
|---|---:|---:|---:|---:|
| 412dp: かな↔QWERTY 30往復 | 72,858 KB | 73,599 KB | 73,190 KB | 119で一定 |
| 412dp: かな・絵文字・音声 20周 | 78,002 KB | 79,039 KB | 78,500 KB | 179で一定 |
| 412dp: IME表示・非表示 20往復 | 79,330 KB | 79,424 KB | 78,934 KB | 178で一定 |
| 840dp: Dual Flick・絵文字 10往復 | 72,468 KB | 72,788 KB | 72,596 KB | 256で一定 |

全観察中の最大サンプルは PSS 79,457 KB（約 77.6 MiB）、RSS 135,768 KB（約 132.6 MiB）。Linux `/proc/32736/status` の `VmHWM` は 174,608 KB（約 170.5 MiB）で、これは Setup / 入力テスト画面を含む同一プロセスの起動後最高 RSS であり、IME 単体のピークを表さない。840dp 測定中は swap が増えたため、412dp と 840dp の PSS を単純比較しない。

この短時間の反復では PSS と View 数の単調増加は見られなかった。ただし `dumpsys` は瞬間のサンプルで、操作中の厳密な最大 PSS は捕捉しない。AVD には端末内日本語音声モデルがなく、音声レイヤーは「日本語の端末内音声モデルがありません」と表示された。実際の認識処理、長時間使用、物理 Fold、低メモリ端末の使用量は未測定。

測定のためだけに変更した既定 IME、録音権限、画面幅、ハードウェアキーボード表示設定、ストレージしきい値は元へ戻し、試験用に導入した APK もアンインストールした。生のサンプルは `/private/tmp/md-kbd-v0.15.31-memory-*.csv` に保存した。

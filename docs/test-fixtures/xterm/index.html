xterm.js IME cursor-key probe

これは実シェルに接続しないローカルの模擬 line editor です。xterm.js の hidden textarea が Android IME の raw key event を受け取れるかだけを確認します。

  1. 下の端末をタップしてフォーカスします。
  2. Gesture IME のターミナル互換カーソルキー設定をONにし、← → ↑ ↓ Home End を各1回押します。
  3. DOM keydown と xterm onData の両方がログに出て、下の入力行の caret が動くことを確認します。

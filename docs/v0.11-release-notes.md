# Gesture IME v0.11.0 release notes

v0.11.0 is an ARM64 APK for Android 9 (API 28) and later. Input, conversion, learning, and emoji recents stay on the device; the app has no network permission.

## Input and candidates

- After Japanese conversion is committed, Mozc can show local next-word candidates in the existing candidate strip. Selecting one appends it and refreshes the prediction without replacing the prior committed text. Password and no-personalized-learning editors never provide surrounding text for this feature.
- The candidate strip now aligns its first face and the gap above the top key with the key geometry. Candidate scrolling, long-press history deletion, voice controls, and Light/Dark behavior remain available.

## Keyboard and settings

- Choose Small, Standard, or Large keyboard height in Setup. The four key rows keep the selected height across app switches, screen widths, rotation, and Dual Flick; the candidate strip and navigation safe area remain outside those rows.
- Setup is edge-to-edge safe on current Android versions: a fixed `masuidrive-kbd 設定` bar stays below status/cutout insets, settings content scrolls below it, and Light/Dark status and navigation icons are set explicitly.
- The Japanese and number layers open an emoji layer. It keeps a device-local, newest-first, distinct recent row of up to eight emojis; its bundled catalog has in-keyboard page controls, including an actionable page indicator.
- New installs enable Dual Flick, English suggestions, and Android personal dictionary lookup by default. Terminal cursor key events remain off by default; existing saved choices are preserved.

## Verification and known limits

- Focused Robolectric tests and the full fast-check, Android unit, lint, and APK suite passed for this release preparation. API 36 emulator evidence covers next-word prediction, fixed height, candidate spacing, setup safe areas, and emoji recents.
- The physical Fold device and on-device Japanese speech recognition remain to be verified. The APK is arm64-v8a only.

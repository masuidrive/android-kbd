# masuidrive-kbd v0.13.0

Android 9（API 28）以降の ARM64 端末向けリリースです。配布物は未圧縮の APK 1 本です。

- [gesture-ime-v0.13.0.apk](https://github.com/masuidrive/android-kbd/releases/download/v0.13.0/gesture-ime-v0.13.0.apk)

## 絵文字

- 絵文字レイヤーは AndroidX Emoji Picker を使い、候補欄の位置にカテゴリのアイコンを表示します。先頭は Recent です。
- 選んだカテゴリの絵文字は 3 行の縦スクロール一覧から選べます。長押しでは肌色などの variation を選べます。
- Recent は端末内に新しい順、重複なしで最大 24 件保存します。機密入力欄では Recent を表示も保存も行いません。
- 最下行のレイヤー切替と削除は、絵文字一覧をスクロールしても固定です。

## 連続音声入力

- 左下のレイヤーキーを左へフリックすると、対応端末では端末内の日本語音声認識を始めます。認識中はキャンセルキーの右に「認識中」と表示します。
- 最終候補を選ぶと、その候補を入力欄へ 1 回だけ確定し、音声レイヤーを閉じずに次の認識を直ちに始めます。続けて話し、候補選択と認識を繰り返せます。
- キャンセルをタップすると認識と未確定候補を破棄して、音声入力前の文字レイヤーへ戻ります。レイヤーや入力欄の切替、IME の非表示、認識エラーでも旧結果は入力しません。
- 音声認識は Android 12 以降で、端末内の日本語認識サービスとモデルがある端末だけで使えます。通信型の認識へ切り替えず、録音音声と認識結果は保存しません。

## 確認状況

- API 36 arm64 エミュレーターで、絵文字のカテゴリ、Recent、3 行 viewport、固定の最下行、Small / Standard / Large の高さを確認しました。
- 412dp と 840dp 相当の公開操作モックで、音声レイヤーの「認識中」、候補を選んだ後の次回認識、Cancel 後の復帰を確認できます。モックはマイクを使いません。
- 実機での日本語発話と Fold 実機での最終確認は継続して確認対象です。

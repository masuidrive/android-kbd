# masuidrive-kbd v0.14.0

このノートは Android の version bump と配布準備前の v0.14.0 向け変更内容です。APK の配布先は、version bump と公開後に追加します。

## 絵文字

- Recent は端末内に新しい順、重複なしで最大100件保存します。101件目では最古の1件を除きます。
- Recent は通常の絵文字gridだけに表示し、文字入力の候補欄shortcutには表示しません。
- カテゴリのアイコンは、選択状態を含めてすべて同じ固定幅です。

## 音声入力

- 音声の最終候補は通常の横候補欄ではなく、固定された音声layer内に1行ずつ縦に表示します。
- 候補を選ぶと入力欄へ1回だけ確定し、一覧を消して「認識中」へ戻り、次の認識を始めます。
- 最終結果がない場合は、最後の有効な途中結果を選択可能な候補として表示します。
- 非対応と認識errorは、音声layer内のtap不能なplain textとして表示し、自動再試行しません。

## キーボード表示

- 独自のキーボードを閉じる行をなくし、AndroidのOS操作でIMEを閉じます。
- 候補・category領域と4行のkey領域は、これらの変更中も固定高です。

## 操作モック

- 入力欄は読み取り専用です。物理キーボードでは入力せず、モックのキー、候補、音声候補で入力と選択位置を操作できます。

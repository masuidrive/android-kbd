# masuidrive-kbd v0.15.0

配布物:

- [gesture-ime-v0.15.0.apk](https://github.com/masuidrive/android-kbd/releases/download/v0.15.0/gesture-ime-v0.15.0.apk)

## 音声入力

- 音声入力レイヤーの最下段を5等分し、左からキャンセル、認識状態、「、。？！」、Space、Enterを配置しました。
- 「、。？！」はtapで「、」、左・上・右フリックで「。」「？」「！」を直接入力します。
- 録音中、認識処理中、候補表示中にも句読点、Space、Enterとそれぞれのフリック操作を使えます。操作しても音声sessionと未確定候補は維持されます。
- キャンセルまたはレイヤー切替の後にキューへ残った音声レイヤーの編集操作は入力されません。

## 操作モックとマニュアル

- 製品トップの操作モックをnativeと同じ5列の音声入力最下段へ更新しました。
- 音声認識の途中と候補表示中に、句読点、Space、Enterを試せます。

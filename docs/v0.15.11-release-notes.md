# masuidrive-kbd v0.15.11

- 記号レイヤーのEscape表示を`Esc`へ揃えました。
- 記号レイヤーの直接入力`:`を`Tab`へ置き換え、タップでAndroidのTabキーイベントを送るようにしました。
- `:`はQWERTYの`m`下フリックに残り、QWERTYと記号レイヤーでSpaceを含む印字可能ASCII 95文字をすべて入力できます。
- 日本語変換中のEnterは、タップで元のひらがな、左または上フリックで全角カタカナを確定するように揃えました。

## 検証

- レイアウト定義でSymbolsが10列のままであること、直接`:`がなく`Esc`と`Tab`が存在することを確認しました。
- QWERTYとSymbolsの印字可能ASCII 95文字が完全一致するunit testを実行しました。
- `KEYCODE_TAB`のdown/up、412dp・840dpで変換中Enterのtap・左・上フリックを自動テストしました。
- API 36.1 AVDでTabによるフォーカス移動と、上フリックによる「さ」から「サ」への確定を実操作で確認しました。

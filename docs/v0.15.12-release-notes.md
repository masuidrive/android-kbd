# masuidrive-kbd v0.15.12

- よく似た音声認識候補を縦に並べたとき、候補間で異なる文字だけを青い太字で表示するようにしました。
- 候補全文、並び順、タップ時の入力内容、候補選択後に次の認識へ進む動作は従来どおりです。
- 長い候補では入力と選択を維持し、比較負荷が上限を超える場合だけ差分装飾を省略します。

## 検証

- API 36.1 AVD上の実Android Viewで、3候補の差分がそれぞれ「を・ほ」「を・欲」「が・欲」だけ強調されることを確認しました。
- 単一候補、同一候補、挿入、補助平面Unicode、重複文字、長文の回帰テストを実行しました。
- 操作モックとAndroidネイティブが同じ差分箇所を強調することを確認しました。

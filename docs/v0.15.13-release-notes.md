# masuidrive-kbd v0.15.13

- 音声入力レイヤーで無言の時間が続き、端末内認識がエラー6または7で終了しても、「認識中」のまま次の発話を待つようにしました。
- 有効な途中結果がある場合は、従来どおり選択可能な候補として残します。
- キャンセル、レイヤー切替、入力欄切替、IME終了後は再開せず、終了済み認識器の遅延結果も入力しません。
- 権限不足、端末内日本語モデル不足、認識器処理中など無音以外のエラーは自動再開しません。

## 検証

- 無音系エラー6・7の再開と、その後の発話候補表示をcontroller・IME serviceの回帰テストで確認しました。
- 途中結果あり、キャンセル、入力欄切替、古いcallback、単発音声、無音以外のエラーを確認しました。
- API 36 emulatorを接続し、fast-checks、unit/lint/APK、instrumentationの全スイートが通過しました。

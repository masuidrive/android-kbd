# masuidrive-kbd v0.15.14

- 入力欄が数字・電話番号・日時を要求するとき、初期レイヤーとしてテンキーを自動表示するようにしました。
- URL・メールアドレス・文字パスワード・ASCII強制欄ではQWERTYを自動表示します。通常の文章欄では最後に手動選択したレイヤーを維持し、自動選択は保存設定を書き換えません。
- 音声入力中の「認識中」の横へ、マイク入力レベルに追従する小さな4本の波形を追加しました。候補待ち、取消、レイヤー切替では消えます。
- 絵文字レイヤー左端に、日本語レイヤーと同じ順の `☺`・`#!`・`19`・`AZ` 切替列を固定しました。絵文字一覧はその右側で7列を維持します。

## 検証

- API 36 arm64 emulatorで数字・電話番号・日時、メール・パスワード、通常欄への復帰を確認しました。
- スマホ幅相当412dpとタブレット幅相当840dpで、4行高、safe area、絵文字7列、初期レイヤーを確認しました。
- fast-checks、全unit test、lint、APK build、接続instrumentationを実行しました。

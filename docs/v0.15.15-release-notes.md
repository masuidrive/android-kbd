# masuidrive-kbd v0.15.15

- 絵文字レイヤーを開くたび、Recentカテゴリと一覧先頭から表示するようにしました。
- 左端に `あ`・`#!`・`19`・`AZ` のレイヤー切替列を固定し、かなレイヤーと同じ幅・タッチ境界へ揃えました。
- 絵文字レイヤーのBackspaceをなくし、右側全体を4行7列のスクロール一覧として使えるようにしました。
- Recentは新しい順・重複なしで最大100件を保持し、private入力欄では表示・保存しません。
- 記号レイヤーの `]` 右へ0.5幅の `⌫` を置き、タップで削除、下フリックでEscを送れるようにしました。

# masuidrive-kbd v0.15.16

- wide画面でAndroidX Emoji Pickerの7列を各slotの中央へ揃え、一覧領域の左右余白を均等にしました。
- 音声候補が空、マイク権限未許可、端末非対応でも最下段のキャンセル・状態・句読点・Space・削除・Enterを表示するようにしました。
- 音声入力のキャンセルから、直前の文字レイヤーへ戻れるタッチ領域を確保しました。
- 通常欄では直接selectionを使い、抽出テキストを提供しない、またはselectionを拒否する非private入力先だけDPAD矢印へ自動fallbackするようにしました。
- private入力欄は自動fallbackでもターミナル向け手動設定でもDPADを送らず、手動設定は非private入力先への強制DPAD送信として維持しています。

## 検証

- API 36.1 arm64 emulatorでwide・phoneの絵文字配置、音声候補なし状態の最下段操作、Cancel復帰を確認しました。
- fast-checks、全unit test、lint、APK build、接続instrumentationを実行しました。

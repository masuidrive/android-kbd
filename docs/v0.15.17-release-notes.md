# masuidrive-kbd v0.15.17

- QWERTYの2行目右端を0.5wの`.`へ入れ替え、タップで`.`、下フリックで`?`を入力できるようにしました。
- QWERTYの3行目右端を1wのBackspaceへ入れ替え、タップで削除、下フリックでEscを送ります。左・上・右へのフリックは入力しません。
- 記号レイヤーのキー配置とBackspace操作は変わりません。

## 検証

- QWERTYの配置、方向操作、412dp・840dp幅での収まりをnativeと操作モックで確認しました。
- QWERTYのlayout・production MotionEvent focused test、fast-checks、lint、APK buildを実行しました。

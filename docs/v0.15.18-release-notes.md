# masuidrive-kbd v0.15.18

- QWERTYと記号レイヤーのBackspaceに、下フリックで送れる`Esc`補助ラベルを表示しました。
- 下へフリックすると`Esc`がキー中央へ移動して拡大し、中央へ戻すとBackspace表示へ戻ります。
- Backspaceの上・左・右フリックは何も入力しません。

## 検証

- QWERTYと記号レイヤーのBackspace表示と方向操作をnativeと操作モックで確認しました。
- focused Robolectric test、fast-checks、lint、APK buildと公開サイトの表示を確認しました。

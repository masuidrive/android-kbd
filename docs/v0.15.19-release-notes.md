# masuidrive-kbd v0.15.19

- 日本語変換中のSpaceを「候補」と表示し、タップで候補を選択・巡回できることを明確にしました。
- 候補を選ぶ前のEnterは「無変換」、Spaceで候補を選んだ後は「確定」と表示します。
- 「確定」をタップすると選択中候補を確定します。Enterの上・左フリックによるカタカナ確定も維持しています。

- focused unit test、Android instrumentation testのコンパイル、全体テスト、APK metadata・権限、製品ページの表示を確認します。

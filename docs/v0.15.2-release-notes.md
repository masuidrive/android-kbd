# masuidrive-kbd v0.15.2

配布物:

- [gesture-ime-v0.15.2.apk](https://github.com/masuidrive/android-kbd/releases/download/v0.15.2/gesture-ime-v0.15.2.apk)

## 音声入力

- 音声入力レイヤーの「、。？！」キーで、左右フリックが縦専用判定に遮られていた問題を修正しました。
- タップ「、」、左「。」、上「？」、右「！」、下「、」を実際のタッチ操作から直接入力できます。
- 記号入力後も録音中・認識処理中・候補表示中の音声sessionと候補を維持します。

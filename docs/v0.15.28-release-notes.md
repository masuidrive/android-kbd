# masuidrive-kbd v0.15.28

- Ctrl+A/C/X/V/S は入力先へ修飾付きのキーイベントを送ります。IME側で選択・コピー・切り取り・貼り付けの編集操作に変換しません。
- Alt+A/C/X/V/S も同じ経路で送ります。CtrlとAltは次の英字キー1回にだけ適用されます。
- パスワード欄でもCtrl+Vのキーイベントを送ります。独立したPaste操作は従来どおりパスワード欄で無効です。
- ブラウザの操作モックもCtrl+Aを独自の全選択に変換しません。ショートカットを実行するかどうかは入力先のアプリによります。

ARM64向けのdebug署名APKです。Android 9（API 28）以上で動作します。

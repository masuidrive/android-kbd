# masuidrive-kbd v0.15.29

- 画像入りクリップボードをPasteすると、画像を受け取れる入力先にはAndroidのコンテンツとして渡します。画像非対応の入力先へURI文字列を貼り付けません。テキストのPasteも継続します。
- 音声入力の候補一覧に「キャンセル」を追加しました。候補だけを破棄して次の認識へ戻れます。下段のキャンセルは音声レイヤーを終了します。
- 無音後に認識器を再準備している間は「準備中」と表示し、発話可能になってから「認識中」と表示します。

ARM64向けのdebug署名APKです。Android 9（API 28）以上で動作します。音声入力はAndroid 12以降で端末内日本語認識サービスとモデルが必要です。認識器の再準備中に話し始めた音声の冒頭は取得できない場合があります。音声候補の実機操作とFold実機は未検証です。

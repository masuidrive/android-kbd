## 音声入力

- 音声入力レイヤー最下段へBackspaceを追加しました。
- 最下段はキャンセル、認識状態、「、。？！」、Space、Backspace、Enterの6列です。
- Backspaceはtapで直前の1文字だけを削除し、フリックでは動作しません。削除後も音声認識と未確定候補を維持します。

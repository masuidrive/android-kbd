## キーボードの高さ

- Android 11（API 30）以降は、current window metricsのnavigation insetを初回measure前に使います。0も、hardware navigationなどで有効な現在値として扱います。
- current window metricsを取得できない場合だけdecor inset、navigation bar resourceの順にfallbackします。回転、navigation mode変更、Fold再構成で古いdecor insetを初回高さへ持ち込まず、4行のキーを安定した位置に表示します。

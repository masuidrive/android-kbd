# masuidrive-kbd v0.15.8

配布物:

- [gesture-ime-v0.15.8.apk](https://github.com/masuidrive/android-kbd/releases/download/v0.15.8/gesture-ime-v0.15.8.apk)

## キーボードの高さ

- 高さをまだ選択していない場合の初期値を「大」に変更しました。初回表示、IME再表示、アプリ切替後も高い4行を維持します。
- 設定画面で「小」「標準」「大」を明示的に選んだ場合は、その選択を維持します。

## 日本語変換

- 変換中のEnterを「無変換」に変更しました。タップと上フリックは先頭候補を選ばず、入力中のひらがなを確定します。
- 左フリックの全角カタカナ確定は維持しています。

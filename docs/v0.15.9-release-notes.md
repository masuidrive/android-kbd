# masuidrive-kbd v0.15.9

- 設定で選んだ「大」がアプリ切替直後の古い短いIME枠へ圧縮される問題を修正しました。
- 初回表示と再表示でnavigation barの余白計算を統一し、hide/show後の高さ変化を止めました。
- 600dp以上で「大」を選んだときは、従来のwide向け62dp row pitchを維持します。
- 高さの初期値を「標準」へ戻しました。「小」「標準」「大」の明示選択はアプリ切替後も維持します。
- 日本語変換中のEnterは先頭候補を選ばず、入力中のひらがなを無変換で確定します。

配布物はARM64向けの未圧縮APKです。Android 9（API 28）以上で動作します。

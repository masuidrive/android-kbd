# Gesture IME v0.5 draft

This draft describes intended behavior. Build, test, APK hash, screenshots, and publication are pending and must not be presented as completed until final verification.

## Manual changes

- The five native keyboard layers are being redrawn from measured values in the preserved HTML source: key shape, 5px corner radius, 1px lower shadow, dark color tokens, label size/baseline, secondary-label spacing, composite ghost labels, and popup geometry.
- Flick feedback keeps the user override that avoids dimming all other key backgrounds. Selection feedback and the selected-candidate accent remain visible.
- QWERTY up/down label motion and Enter→Paste use one consistent animation relationship. The HTML navigation path omitted the normal secondary-label transform; v0.5 corrects that source-side mismatch instead of copying it.
- Popups use a nonfocus, nontouch overlay so top-row previews can extend over the candidate region without adding a permanent gap or stealing keyboard input. Android 9 compatibility and screen-edge clamping require final device verification.
- QWERTY label adjustments remain saved as relative changes from the new measured defaults. Reset restores the new defaults.
- Candidate-area and unselected-candidate backgrounds remain `#29292c` whether candidates are empty or present. The currently selected candidate retains its accent.
- The common layer gesture is now left Symbols, up Kana, right QWERTY, and down Numbers. Tap destinations and the one-second voice hold remain unchanged.

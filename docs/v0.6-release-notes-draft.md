# Gesture IME v0.6 draft

この文書は公開前の原稿です。v0.5の新サイトとv0.6 APKはいずれも未公開であり、最終ビルド、端末確認、ハッシュ照合、公開承認が揃うまで利用可能とは案内しません。

## 製品紹介への追記案

英字候補は、必要なときだけ設定で有効にできます。入力した英字は候補が表示されても自動では置き換わらず、候補をタップしたときだけ選んだ単語で確定します。辞書の検索は端末内で完結し、入力履歴の学習、同期、ネットワーク送信は行いません。

## マニュアルへの追記案

1. Gesture IMEの設定を開き、「英数字候補」を有効にします。初期設定は無効です。ターミナル向けカーソル設定とは別に切り替えられます。
2. 半角の英字・数字を続けて入力すると、未確定のまま保持します。英字だけのときは、その文字で始まる単語を候補欄へ最大5件表示します。数字が混ざる場合は候補を表示せず、入力した文字は維持します。
3. 候補をタップすると、入力中の英字をその候補に置き換えて確定します。候補をタップしない限り、入力した文字を別の単語へ自動置換しません。
4. 入力中にSpaceを押すと、入力した英字・数字をそのまま確定してから空白を入力します。Enterを押すと、入力した英字・数字だけをそのまま確定します。この場合は改行や送信を追加しません。入力中の英字・数字がないときのEnterは、従来どおり入力欄の改行または送信です。

パスワードなどのprivate入力欄では英字候補を表示しません。辞書は固定された一般英単語リストで、個人辞書、入力履歴の学習、クラウド同期には対応していません。候補の大文字と小文字は、入力した表記を保ちます。

## 公開前に必要な証拠

- 設定が初期OFFで、ON/OFFがIMEへ反映される端末画面。
- 候補表示中も入力原文が変わらず、候補タップだけが置換確定する実入力。
- Space、Enter、Backspace、数字混在、private入力欄、QWERTY以外への切替境界。
- 連続入力中に古い非同期候補が戻っても表示や確定に使われないこと。
- 固定wordfreqデータの出典、CC BY-SA 4.0帰属、再生成一致。
- 全unit/connected/lint/build、APKとZIPのSHA-256、公開先の全ファイル照合。

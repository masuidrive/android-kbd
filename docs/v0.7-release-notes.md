# Gesture IME v0.7.0

v0.7.0 adds automatic Light/Dark theme support to the Android keyboard. The keyboard background, regular and special keys, labels, candidate area, flick popup, and QWERTY label adjustment preview follow the device theme without a separate Gesture IME setting.

The product site and manual also follow the browser's preferred color scheme and include Android screenshots of both themes.

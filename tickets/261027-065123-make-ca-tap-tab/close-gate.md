# C/A キーの中央 T を Tab にする — 完了確認

## 決定サマリー

QWERTY と記号レイヤーで Tab を見つけやすくし、タップ回数を減らすための変更です。ユーザーには、この達成でチケットを閉じてよいかを判断していただきます。**閉じることを推奨します。** Android 実画面とブラウザデモで中央 T の表示と Tab 動作を確認し、最終実装の全テストが通りました。保存データの形は変えていません。キー中央の未選択タップは無動作から Tab 送信に変わります。物理端末と 840dp の実画面、TalkBack の実聴は未確認です。レビューで新たな誤入力や表示崩れが見つかったら公開を止めます。

## 出来上がりの像

従来の C/A キーは、未選択時に中央の文字がなく、中央タップは無動作でした。完成版は上 C、中央 T、下 A と表示されます。下の画像は最終 APK を Android 16、412dp 相当のエミュレータに入れ、同じ入力テスト画面で撮ったものです。中央の T を押すと、通常入力欄から数値欄へフォーカスが移りました。

## 受け入れ条件ごとの達成

- **QWERTY と記号レイヤーの C/A キーは中央に「T」を表示し、中央タップで入力先へ Tab キーを送る。** Android 実画面の両レイヤーで表示と入力欄間のフォーカス移動を確認しました。恒久テストでは本番 KeyboardView に MotionEvent を送り、412dp と 840dp 相当のタップ経路を確認しました。
- **同じキーの上フリックは次の1キーに Alt、下フリックは次の1キーに Ctrl を適用し、選択中の A/C 表示と解除操作を維持する。** Android 実画面で A/C 選択表示と、Alt 選択中の中央タップが解除だけを行うことを確認しました。恒久テストでは両方向と修飾状態を確認しました。
- **ブラウザの操作デモでも中央「T」と Tab の動作を確認できる。** ローカル製品ページで Mobile 412px と Tablet の表示、クリック後のタブ文字入力、修飾状態解除を確認しました。

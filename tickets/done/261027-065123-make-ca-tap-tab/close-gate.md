# C/A キーの中央 T を Tab にする — 完了確認

## 決定サマリー

QWERTY と記号レイヤーで Tab を見つけやすくし、タップ回数を減らすための変更です。ユーザーには、この達成でチケットを閉じてよいかを判断していただきます。**閉じることを推奨します。** Android 実画面とブラウザデモで中央 T の表示と Tab 動作を確認し、最終実装の全テストが通りました。変更ファイルを列挙し、保存データの読み書き経路が差分にないことを確認しました。キー中央の未選択タップは無動作から Tab 送信に変わります。物理端末と 840dp の実画面、TalkBack の実聴は未確認です。レビューで新たな誤入力や表示崩れが見つかったら公開を止めます。

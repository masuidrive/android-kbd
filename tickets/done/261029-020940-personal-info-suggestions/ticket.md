## 261029-020940-personal-info-suggestions

### Why
氏名・メールアドレス・住所や定型文を繰り返し手入力する負担を減らす。Product Brief の「同じジェスチャー体系で素早く操作したい」と「入力内容を外部へ送らない」に沿う。

### What / Acceptance Criteria
この ticket が終わると、masuidrive-kbd の利用者が、設定に登録した表記別の氏名・メールアドレス・分割した住所と定型文を、入力欄に応じた候補または候補欄のカードアイコンで開くキーボード上の一覧から選んで入力できるようになる。

- [x] AC 1: 利用者は設定画面で氏名の漢字・ひらがな・カタカナ・英字を各1つのフルネームとして、メールアドレスを独立した4枠に、住所の郵便番号・都道府県・市区町村・住所1・住所2と複数の定型文を登録、変更、削除でき、既存登録値も失わず再起動後に使える。
- [x] AC 2: 利用者がメール・氏名・住所の種類を明示した通常の入力欄を開くと、候補欄に枠のない控えめなカードアイコンと登録済みの該当候補がキー間隔相当の余白を挟んで右に現れ、入力可能な間は一瞬で消えずに残る。メール欄には登録済みの最大4件を個別候補として並べる。氏名4表記は登録値の空白で姓・名を個別候補に分け、住所各項目も連結せず個別に並び、候補のタップでその欄へ順に入力される。入力ビューの再表示後も該当候補が復元される。
- [x] AC 3: 利用者が文字入力中でない通常の欄で候補欄のカードアイコンを押すと、そのアイコンが同じ位置の戻る矢印に変わり、キーのある領域の上側には登録済みメールアドレスだけが値ボタンとして並ぶ。最下段には左端に通常のレイヤー切り替えキー、その隣に「more..」、右側に音声入力レイヤーと同じ句読点・Space・Backspace・Enterを置く。「more..」を押すと上側に氏名各表記の姓・名、住所各項目・定型文も項目名なしの値ボタンとして詰めて折り返し表示される。最初の候補はキー間隔相当の左余白を持ち、下段の画面端余白とキー間隔は通常のキー配置に揃え、Spaceは他の下段キーのおよそ2倍幅とする。レイヤー切り替え・句読点・Space・Backspace・Enterは通常キーと同じ割当方向をフリックでき、未割当方向はタップと同じ動作にする。全体の高さは変わらない。項目のタップではその値だけを入力して一覧を保ち、必要な項目を順に押せる。戻る矢印は入力せず元のキーボードへ戻り、切り替えキーは通常のレイヤーキーと同じ遷移をする。空欄の項目は一覧に出ない。
- [x] AC 4: 利用者がパスワード欄などの非公開入力欄を開いても、登録した個人情報とそのアイコンは候補欄に出ない。
- [x] AC 5: 利用者が Bitwarden などのインライン自動入力候補を受け取るメール欄を開くと、保護されたインライン候補と登録メール候補が候補欄に並んで表示され、どちらもタップでその欄へ入力できる。

### Architectural Invariants check
AI-1〜AI-4 と矛盾しない。登録値は端末内に保持し、入力先へは利用者が選んだ時だけ送る。非公開欄では登録値を候補化しない。

### Design Decisions
- 登録枠は氏名4表記・メールアドレス4件・住所5項目とし、定型文は複数登録できる。空値の保存で削除する。既存のメールアドレスは1枠目に残し、旧住所値は住所1として読み込み、保存時に引き継ぐ。複数プロファイルは今回扱わない。
- 入力先の種類は `EditorInfo.inputType` の明示情報だけで自動判定する。一般的なWebフォームのラベルや名前から推測しない。
- 候補欄には左から枠のない低コントラストのカードアイコン、10dp空けた該当候補の順で置く。カードの一覧を開くと同じ位置のアイコンを戻る矢印に切り替え、固定高のキーボード領域はまずメールアドレスだけをキー間隔相当の左余白から表示する。最下段の左端に通常のレイヤー切り替えキーと「more..」、右側に句読点・Space・Backspace・Enterを置き、「more..」で氏名・住所・定型文も上側に展開する。値の選択後も一覧を保ち、戻る操作で前のレイヤーへ戻す。
- 氏名4表記はそれぞれ1つのフルネームで登録し、候補では空白区切りの姓と名を個別の値にする。登録値に空白が無い場合は推測で姓名を切らず、1候補として扱う。
- 種類を判定できない欄には、登録内容を自動で並べず、カードアイコンから利用者に選ばせる。
- 既存のインライン Autofill はサービス側の保護Viewのまま表示し、メール欄ではその横に登録メール候補を併記する。提供元の候補内容は読まない。

### Out-of-scope
Bitwarden の保存情報の取得、Android の AutofillService の実装、SMS/Gmail の一時コード、カード情報、登録値の端末間同期は扱わない。
